# Agile Software Development (Beginner Notes)

## What is Agile?

Agile is a way of developing software where teams build software in
**small pieces**, get feedback quickly, improve continuously, and
deliver value faster.

> "Build a small part, release it, get feedback, improve it, then
> repeat."

## Waterfall vs Agile

### Waterfall

``` text
Planning
  ↓
Design
  ↓
Development
  ↓
Testing
  ↓
Deployment
```

### Agile

Deliver small increments, collect feedback, and improve continuously.

## Why Agile?

-   Faster delivery
-   Early customer feedback
-   Easier to handle changing requirements
-   Better collaboration
-   Lower project risk

## Agile Manifesto (4 Values)

1.  Individuals and interactions over processes and tools
2.  Working software over comprehensive documentation
3.  Customer collaboration over contract negotiation
4.  Responding to change over following a plan

## Key Principles

-   Deliver software frequently
-   Welcome changing requirements
-   Business and developers work together
-   Working software is the primary measure of progress
-   Continuously improve

## Agile Team

-   Product Owner
-   Scrum Master
-   Developers

-   UI/UX Designers
-   DevOps Engineers

## Sprint

A Sprint is a fixed time period (usually 2 weeks) to complete a set of
work.

## Scrum Ceremonies

-   Sprint Planning
-   Daily Stand-up
-   Sprint Review
-   Sprint Retrospective

## Product Backlog

Master list of all features.

## Sprint Backlog

Selected items for the current sprint.

## Increment

A usable version of the product produced at the end of each sprint.

## User Story

> As a user, I want \_\_\_ so that \_\_\_.

## Acceptance Criteria

Conditions that define when a user story is complete.

## Story Points

Common estimates: 1, 2, 3, 5, 8, 13, 21

## Agile Frameworks

-   Scrum
-   Kanban
-   Extreme Programming (XP)
-   Lean

## Agile + DevOps

Agile helps teams develop software quickly.

DevOps helps teams build, test, deploy, and monitor automatically.

## Waterfall vs Agile

  Feature    Waterfall       Agile
  ---------- --------------- ------------
  Delivery   End             Frequent
  Feedback   Late            Continuous
  Changes    Difficult       Welcome
  Testing    Mostly at end   Throughout

## Key Takeaways

-   Agile is a mindset.
-   Scrum is the most popular Agile framework.
-   Work is done in sprints.
-   Continuous feedback improves quality.
-   DevOps complements Agile with automation.
